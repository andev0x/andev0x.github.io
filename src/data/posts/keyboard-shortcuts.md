# Keyboard Shortcuts Reference

> Complete reference for all keyboard shortcuts available in the knowledge system.

## Context

Efficient navigation requires muscle memory. This reference documents all available keyboard shortcuts.

## Global Shortcuts

These work from anywhere in the application:

| Key | Action |
|-----|--------|
| `Cmd/Ctrl + K` | Open command palette |
| `/` | Focus search |
| `:` | Open command palette |
| `Escape` | Close modal / go back |
| `?` | Show keyboard shortcuts |

## List Navigation

When viewing a list of posts:

| Key | Action |
|-----|--------|
| `j` | Move selection down |
| `k` | Move selection up |
| `Enter` | Open selected post |
| `g` | Go to first item |
| `G` | Go to last item |

## Post View

When reading a post:

| Key | Action |
|-----|--------|
| `j` | Scroll down |
| `k` | Scroll up |
| `g` | Scroll to top |
| `G` | Scroll to bottom |
| `h` | Go back home |
| `[` | Previous post |
| `]` | Next post |
| `t` | Toggle table of contents |
| `c` | Copy article link |
| `Escape` | Go back home |

## Command Palette

The command palette (`Cmd+K`) provides quick access to:

- Search across all posts
- Navigate to specific posts
- Toggle dark/light mode
- Access settings

## TL;DR

Master these shortcuts: `Cmd+K` for commands, `j/k` for navigation, `Enter` to select, `Escape` to go back.
